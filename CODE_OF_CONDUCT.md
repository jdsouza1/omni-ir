# Code of conduct

Omni-IR adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies to every project space: issues, pull requests, discussions, and anywhere someone represents the project.

In short: be welcoming and respectful, accept constructive criticism gracefully, and focus on what is best for the people using the project. Harassment, insults, personal or political attacks, and publishing others' private information are not acceptable.

## Reporting

To report a problem privately, use the repository's private reporting form: **Security → Report a vulnerability** on GitHub, starting the title with "Conduct:". Only the maintainer can read it. A dedicated email address will be added here later.

Reports are handled by the maintainer ([GOVERNANCE.md](GOVERNANCE.md)), kept confidential, and answered within a week. Consequences follow the Contributor Covenant's enforcement guidelines: a private warning, a temporary ban, or a permanent ban, depending on the seriousness of the behaviour.
